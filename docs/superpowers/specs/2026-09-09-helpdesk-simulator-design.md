# Тренажёр службы поддержки — дизайн

**Дата:** 2026-09-09
**Статус:** дизайн утверждён; уточнён после разбора оригинала изнутри (с логином)
**Ориентир:** sysdesks.com — воспроизводим workflow, пишем свой контент и код

---

## 1. Задача

Локальный тренажёр Tier 1 help desk: очередь тикетов, симулированные инструменты
администратора, оценка не только результата, но и способа работы.

Пользователь один — автор. Тренируется сам, регулярно, оффлайн.

### Что делаем

Полный функциональный паритет с ориентиром.

### Чего не делаем

- Регистрация, аккаунты, мультиюзерность, биллинг, публичный хостинг
- Копирование текстов, сценариев, курсов и оформления ориентира
- Настоящие виртуальные машины
- Серверная часть

### Ограничения

- **Работает без сети и без денег.** Платное и сетевое — только отключаемые надстройки
- **Ядро детерминированное.** Сценарии — статические файлы, без генерации на лету
- Запуск: `npm run dev`

## 2. Что подтвердилось в оригинале живьём

Проверено вручную в работающем продукте, не по маркетингу.

| Проверка | Результат |
|---|---|
| Формат вывода команд | Настоящий, вплоть до `169.254.23.11(Preferred)` без пробела |
| Состояние меняется по-настоящему | `/release` + `/renew` → IP `169.254.23.11` стал `10.20.14.88`, появились шлюз, DNS, сроки аренды |
| Связность инструментов | После починки в терминале иконка Wi-Fi в трее сама сменилась с `no connectivity` на `connected`, панель устройства в тикете — на `connected` |
| Последовательность важна | `ipconfig /renew` в одиночку падает (`unable to contact your DHCP server`); `release` → `renew` проходит |
| Шлюз полномочий | `netsh advfirewall set allprofiles state off` → **`Access is denied.`** |
| Оценка настоящая | Задача решена верно и заметка подробная, но вердикт **PARTIAL** «process/comms can improve» — потому что не перезвонил юзеру после починки |

Последняя строка — важнейшая. Их доктрина «подтверждает заявитель, а не техник»
реально считается в баллах. Юзер в логе звонка спорил («I'm still getting the DNS
error»), тикет был закрыт без повторного подтверждения — и балл снят.

## 3. Архитектура

### 3.1 Состояние мира

Единственный источник истины. Все инструменты — окна над ним.

```
WorldState
├─ org
│  ├─ users[]      samAccountName, displayName, dept, title, phone, manager,
│  │               groups[], ou, enabled, lockedOut, pwdExpired, pwdLastSet,
│  │               deskLocation, primaryDevice
│  ├─ groups[]     name, ou, members[], grantsAccessTo[]
│  ├─ ous[]        path, parent
│  └─ computers[]  name, ou, assignedTo
│
├─ devices{}  ключ — имя хоста
│  ├─ adapters[]  name, mac, dhcpEnabled, ip, mask, gateway, dns[],
│  │              leaseObtained, leaseExpires, linkUp, mediaState
│  ├─ services[]  name, displayName, status, startType
│  ├─ processes[] pid, name, cpu, mem
│  ├─ eventLog[]  log, level, source, eventId, time, message
│  ├─ drivers[]   device, version, status, problemCode
│  ├─ disks[]     letter, totalGb, freeGb, health
│  ├─ printers[]  name, isDefault, status, queue[], driver, port
│  ├─ software[]  name, version
│  └─ desktop     иконки, файлы пользователя, состояние окон

│  └─ reachability(откуда, куда) → ok | timeout | unreachable
│
├─ cmdb           активы: тег, тип, вендор/модель, владелец,
│                 жизненный цикл, место хранения, гарантия
├─ shipments[]    тип, направление, актив, тикет, статус, трекинг
```

### 3.2 Модель тикета

Уточнена по оригиналу.

```
Ticket
├─ number            INC3523884
├─ summary
├─ description       текст от заявителя, первое лицо
├─ service           «Corporate Network»
├─ category          двухуровневая: «Networking › Connectivity»
├─ priority          P1…P4
├─ assignmentGroup   «Service Desk Tier 1»
├─ slaResponse       отдельный срок
├─ slaResolve        отдельный срок
├─ status            New · Assigned · In progress · Pending user · Completed
├─ resolutionCode    Solved (Permanently) · Escalate ·
│                    Not Solved (Not Reproducible) · Closed (Cancelled by User)
├─ workNotes         внутренние
├─ resolutionNotes   видимые заявителю при закрытии
├─ requester         имя, роль, отдел, почта, кабинет
├─ device            хост, тег актива, модель, IP, состояние связи
└─ communications[]  единая лента CALL / CHAT / MAIL
```

**Статус не закрывает тикет.** Рабочий статус и резолюция — разные вещи;
в оригинале это прямо написано в интерфейсе. Воспроизводим.

**Правила очереди:**

- **Один тикет в работе за раз.** Остальные показывают «закончи текущий»
- Закрытие тикета догенерирует новые в очередь
- Тикет можно скрыть из очереди без штрафа
- Закрытие **публикует статью в базу знаний** (Draft, v1.0)

**Цели — это и есть критерии оценки.** Процессные цели (подтвердить у юзера,
написать заметку, выбрать код) стоят наравне с техническими. Задача, решённая
без них, даёт частичный балл — проверено на практике.

### 3.4 Порядок команд имеет значение

Команда — не таблица «вход → выход», а переход состояния с предусловиями.
`renew` при удерживаемом APIPA-адресе обязан падать; после `release` — проходить.
Такие предусловия описываются в команде, а не в сценарии.

### 3.5 Инструменты как чистые функции

```
run(cmdline, world, session) → { stdout, exitCode, mutations[] }
```

Три класса: полная симуляция · правдоподобный вывод с ограниченным эффектом ·
отказ по политике (`Access is denied.` + запись опасного действия).

### 3.6 Шлюз полномочий

```
authorize(действие, world, session) → allow | deny | allow-with-flag
```

Правила, подтверждённые в оригинале:

1. Личность подтверждена до изменения, привязанного к аккаунту
2. Защитный контроль не отключается
3. Общая система не меняется ради одного человека
4. Действие проговаривается до выполнения в удалённой сессии
5. Вне прав — эскалация с приложением собранного
6. Отказ фиксируется в тикете
7. **Удалёнка только к машине с открытым тикетом.** Машины без инцидента не видны
8. **Изменения инфраструктуры проверяются против области тикета**
9. **Отправка оборудования только по тикету, который её оправдывает**

### 3.7 Голосовой звонок

В оригинале это полный контур: **микрофон → распознавание речи → LLM с персоной →
синтез речи**. Воспроизводится целиком бесплатно и локально:

| Звено | Бесплатно и локально | Запасной вариант |
|---|---|---|
| Распознавание | whisper.cpp / faster-whisper | Ввод текстом с клавиатуры |
| Диалог | Ollama (OpenAI-совместимый эндпоинт) | Реплики из файла сценария |
| Синтез | Piper (нейронный, оффлайн) | `speechSynthesis` браузера |

Клиент диалога **один** — Ollama и облачный API говорят на одном протоколе,
различие в конфиге (`baseUrl`, `apiKey`, `model`).

**Обязательные свойства:**

- **Деградация.** Любое звено недоступно → откат на текстовый ввод и скриптовые
  реплики с плашкой. Тренировка не зависит от того, поднята ли сегодня модель
- **Модель не знает разгадку.** В промпт уходит только `persona.knows`.
  Корневая причина не передаётся никогда
- **Заявитель — не оракул.** Он сообщает то, что видит со своей стороны, а не
  состояние мира. Починенная машина не означает, что юзер сразу подтвердит
- **Ключ не в бандле.** Запросы через прокси dev-сервера, конфиг в `.gitignore`

## 4. Оценка

Шесть измерений, все считаются из `session`.

| Измерение | Из чего вычисляется |
|---|---|
| Владение тикетом | Взят до начала действий · порядок статусов · не оставлен открытым · SLA |
| Расследование | Доля релевантных проверок до изменения · лишние действия · по одному изменению за раз |
| Документация | Заметка 0–10 по рубрике ниже |
| Коммуникация | Личность до изменения · вопросы про масштаб и изменения · предупреждение перед действием · **подтверждение от заявителя после починки** |
| Границы полномочий | Верный код закрытия · общее не тронуто · ноль опасных действий · отказ зафиксирован |
| Качество решения | Целевое состояние · подтверждено · нет побочного ущерба · при эскалации приложено всё |

**Вердикты:** полный · частичный · провал. Оригинал выдаёт короткую формулировку
вида «Resolved — process/comms can improve» плюс очки.

**Тихие поломки.** Отдельная метрика: активные и **тихие** неисправности.
Тихая — вы что-то сломали и не знаете. Именно сюда попадает «прописал статический
IP вместо эскалации»: интернет работает, тикет закрыт, мина заложена.

### 4.1 Оценка заметки без модели

Сверкой с журналом — известно, что произошло на самом деле.

| Часть рубрики | Проверка |
|---|---|
| Симптом как описал заявитель | Совпадает со сказанным, а не с переформулировкой в диагноз |
| Что проверили и что исключили | Названы команды из `session.commands`, включая хотя бы одну без находки |
| Какое одно изменение | Названо конкретное значение из `session.changes` |
| Как подтвердили | Подтверждение есть в `session.dialogue` и заметка на него ссылается |
| Что нужно следующему | При эскалации — все обязательные приложения |
| Штрафы | Пароль открытым текстом · «починил» без конкретики · подмена симптома диагнозом |

После закрытия показывается построчно, что засчитано и почему.

## 5. Интерфейс

Две панели: слева постоянный контекст инцидента, справа активный инструмент.
Поверх всего — **плавающий док связи**: мои тикеты · подсказка · звонок · сообщения.
Он виден и внутри удалённой сессии.

**Разделы:** Тикеты · Почта · Интервью · Active Directory · Серверная ·
Удалёнка · Документация · Курсы · Активы · Логистика · Лидерборд · Профиль · Настройки.

### 5.1 Удалёнка — это целый рабочий стол

Не набор окон с инструментами, а симуляция Windows: обои, иконки на десктопе,
файлы пользователя, панель задач, системный трей с иконками безопасности,
сети, громкости и часами, окна с кнопками свернуть/развернуть/закрыть.
Панель RDP сверху: Ctrl+Alt+Del, настройки экрана, синхронизация буфера,
полный экран, отключиться.

Приложения на рабочем столе: проводник, браузер, командная строка, параметры,
VPN-клиент, портал ПО, просмотр фото, почтовый клиент.

**Иконки трея читают состояние мира** — это дешёвый и очень заметный способ
показать связность.

### 5.2 Пародийные бренды

Оригинал системно заменяет вендоров, чтобы не трогать товарные знаки.
Нам нужен свой такой словарь: ОС, браузер, почта, офисный пакет, мессенджер,
облако, производители ноутбуков/десктопов/планшетов/принтеров/телефонов/
периферии/сетевого оборудования. Заводится один раз в файле констант.

## 6. Прогрессия

- **Ранги:** стажёр → Tier 1 → следующий уровень; переход по очкам (в оригинале 500)
- **Очки** за тикет — порядка нескольких десятков, зависят от вердикта
- **Счётчики:** закрыто · без единой ошибки · серия · неисправности (активные/тихие)
- **Лидерборд:** ник, уровень и роль, число решённых, значки, очки
- **ИИ-разбор профиля:** сильные стороны, что качать, на чём сфокусироваться —
  единственное место, где модель действительно уместна; при её отсутствии
  показывается сводка по шести измерениям

| Инструмент | Модель |

| **Логистика** | Типы отправлений (гарнитура на стол, RMA телефона, комплект кабелей, замена дока/монитора, RMA вендору, входящее оборудование, подменный фонд, утилизация). Направление, привязка к активу и тикету. **Статус двигается по таймеру** |

## 10. Риски

| Риск | Оценка |
|---|---|
| **Контент — длинный хвост** | Оригинал: 72 сценария + 10 курсов по ~68 проверок. Это сотни единиц контента. Движок недели, контент месяцы |
| **Достоверность вывода команд** | Проверять по реальному Windows; формат виден построчно |
| **Заучивание** | Параметризация инъекций при неизменной сути поломки |
| **Слабая модель ломает роль** | Разгадка не передаётся в промпт в принципе |
| **Голосовой контур из трёх звеньев** | Три точки отказа. Обязателен откат на текст и скрипт |
