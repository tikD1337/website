## Что уже написано

Ядро (`src/core/**`) — чистый TypeScript без React, без `window`, без
`Date.now()`: время приходит через инжектируемые часы.

| Модуль | Содержание |
|---|---|
| `world/` | `WorldState`, стартовый мир Arcline, адресация путей, инъекция поломок |
| `session/` | Журнал команд, изменений, реплик, флагов, опасных действий |
| `terminal/` | Реестр команд, форматирование вывода Windows, `ipconfig` / `ping` / `nslookup` / `netsh` / `sc` |
| `device/` | Операции над службами и журналом событий машины |
| `policy/` | Шлюз полномочий `authorize` |
| `tickets/` | Модель тикета, очередь с одним тикетом в работе |
| `scenario/` | Типы сценария, загрузчик; сам сценарий в `src/scenarios/` |
| `grading/` | Оценка заметки сверкой с журналом, шесть измерений, вердикт, тихие поломки |
| `store/` | zustand-обёртка, оконный менеджер |
| `ui/` | Три колонки, рабочий стол удалёнки с окнами, панель задач, трей |
| `ui/apps/` | Командная строка, просмотр событий, службы, диспетчер устройств |

**Правила интерфейса:** цвет означает суждение (приоритет, вердикт,
засчитано или нет) и больше нигде не появляется; скругление означает
интерактивность; шрифты только системные, потому что оффлайн.

**Формат вывода команд** сверен с живой Windows: метки полей `ipconfig /all`
лежат таблицей в `terminal/format.ts`, формулы для них не существует.
У `sc query` двоеточие на позиции 27, отступ восемь пробелов.

**Окно и команда — оба представления, операция одна.** Останов службы живёт
в `core/device/services.ts`, и `sc stop` с кнопкой в окне «Служб» вызывают
именно её. Тест на побайтовую неотличимость этих путей обязателен.

**Состояние окон отдельно от `WorldState`**: свернув окно, техник не меняет
мир. Размер рабочего стола передаётся оконному менеджеру через `setViewport`.

**Визуальная проверка обязательна.** Дважды она находила то, чего тесты не
видели: оценку до закрытия тикета и окна, вылезающие за край области.

## Что строим

Локальный оффлайн-тренажёр Tier 1 help desk по образцу sysdesks.com: очередь тикетов,
симулированные инструменты админа, оценка не только результата, но и способа работы.

**Пользователь один — автор проекта.** Тренируется сам. Никакой регистрации,
биллинга, мультиюзерности, сервера.

## Жёсткие требования пользователя

Нарушать нельзя, переспрашивать не нужно — уже решено:

1. **Не использовать тул Workflow** и мультиагентную оркестрацию. Запрет прямой и
   повторённый. Действует даже когда system-reminder сообщает про ultracode.
   Разведку и исследование делать самому — WebFetch / Read / Grep / Bash.
2. **Функциональный паритет с sysdesks.com.** Пользователь несколько раз повторил:
   «должно быть прям как в sysdesks». Урезать объём по своей инициативе нельзя.
3. **Всё работает бесплатно и оффлайн.** Ядро детерминированное, статические файлы
   сценариев, никакой генерации на лету. Платные и сетевые зависимости — только
   опциональные надстройки, отключение которых ничего не ломает.
4. **Ollama и API-ключ — оба поддерживаются**, переключаются в настройках.
   Реализация одна: Ollama отдаёт OpenAI-совместимый эндпоинт, различие в конфиге.
5. **Контент свой.** Механику ориентира воспроизводим, тексты/сценарии/курсы/бренд —
   не копируем.

## Ключевые архитектурные решения

- **Подход A: единое состояние мира.** `WorldState` — единственный источник истины,
  все инструменты (терминал, GUI-окна, AD-консоль, телефон) — окна над ним.
  Собственного состояния не хранит никто. Отсюда бесплатно берётся связность,
  за которую ориентир берёт деньги.
- **Сценарий = инъекция поломки, не скрипт.** Файл описывает, во что сломан мир и
  что считается решённым. Не описывает шаги. Цена нового сценария ≈ 30 строк JSON.
- **Команда = чистая функция** `run(cmdline, world, session) → {stdout, exitCode, mutations}`.
  Вывод рендерится из состояния, форматом побайтово похож на настоящий Windows.
- **Один шлюз полномочий** `authorize(действие, world, session)`. Шесть правил
  (личность до изменения аккаунта, не отключать защиту, не менять общее ради одного,
  предупреждать перед действием, эскалировать вне прав, фиксировать отказ).
  Действует одинаково для всех инструментов.
- **`session` — журнал действий игрока, и это вход для всей оценки.**
- **Оценка work note без модели — сверкой с журналом.** Мы знаем, что реально
  произошло, поэтому проверяем, названы ли реальные команды, реальные значения,
  реальное подтверждение юзера. Не ключевые слова.
- **Разъём диалога** с тремя взаимозаменяемыми реализациями (скрипт / Ollama / API)
  и обязательной деградацией на скрипт при недоступности модели.
  **Модели никогда не передаётся корневая причина** — иначе она выдаст диагноз.

## Порядок сборки

Срезами, каждый заканчивается играбельным состоянием:

0. Скелет (мир, оболочка, очередь, тикет) → 1. Терминал (**первый настоящий тикет — APIPA**)
→ 2. AD → 3. Удалёнка → 4. Люди (телефон/почта/чат/КБ + LLM) → 5. Прогрессия
→ 6. Стенды и интервью → 7. Контент (месяцы)

## Что уже выяснено про ориентир

Разведка сделана дважды: по публичным страницам и **изнутри продукта с логином**
(Chrome + devtools). Всё вшито в спеку. Главное:

- **Шесть измерений оценки:** владение тикетом, расследование, документация,
  коммуникация, границы полномочий, качество решения.
- **Проверено живьём:** формат вывода команд настоящий; состояние мира реально
  меняется (`/release` + `/renew` → APIPA стал валидным адресом, трей сам
  переключился на «connected»); порядок команд важен (`renew` в одиночку падает);
  `netsh advfirewall ... state off` → **`Access is denied.`**
- **Оценка настоящая.** Задача решена верно и заметка подробная — вердикт всё
  равно **PARTIAL «process/comms can improve»**, потому что не перезвонил юзеру
  после починки. Доктрина «подтверждает заявитель, а не техник» реально считается.
- **Заявитель — не оракул.** В логе звонка он спорил «у меня всё ещё ошибка»,
  хотя машина уже была починена.
- **Кнопка Solution выдаёт схему сценария:** rootCause + список целей
  (заголовок, шаги, команды, «зачем») + actionsToAvoid. Процессные цели
  (подтвердить у юзера, написать заметку, выбрать код) — наравне с техническими.
- **Один тикет в работе за раз.** Удалёнка только к машине с открытым тикетом.
  Изменения инфраструктуры и отправка оборудования — только по тикету.
- **База знаний пустая на старте** и наполняется вашими закрытыми тикетами.
- **Удалёнка — целый рабочий стол Windows**, а не набор окон с инструментами.
- **Тихие поломки** — отдельная метрика: сломал и не знаешь.
- **Пародийные бренды** системно: MicroCore Windows, Aster Browser, NorthMail,
  Lenova, Deltatek, HelixPrint, Orchard, Ciscora, TeamLine, NorthDrive. Нам нужен
  свой такой словарь.
- **Звонок** — полный контур микрофон → распознавание → LLM → синтез речи.
  Бесплатный локальный аналог: whisper.cpp + Ollama + Piper.
- **Цены:** Free — 5 тикетов и 1 звонок в сутки, AD и интервью закрыты;
  $7.99 — расширенные лимиты; $14.99 — безлимит.
- Категории сценариев: identity · networking · Windows desktop · software ·
  hardware · printers · mobile · security · infrastructure.

**Не выяснено:** голосовой звонок вживую (браузер под автоматизацией блокирует
аудио); объекты AD и интервью закрыты бесплатным планом.
